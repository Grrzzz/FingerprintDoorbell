Manual update

Install a release package (update.zip) or a single firmware.bin / spiffs.bin from this computer. The type is detected from the file name. Your settings are kept. A package installs the web interface first, then the firmware. The device restarts afterwards.

Drop a package here
or browse your computer · *.zip, firmware.bin, spiffs.bin, max. 4 MB
